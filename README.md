# Fredzz Website

Public landing page and browser-based business assistant.

- `index.html` — Fredzz landing page
- `app/index.html` — business dashboard and AI assistant
- `app/style.css` — application styles
- `app/script.js` — application logic

Business records are stored in this browser only. Gemini AI requires your own API key in Settings. Do not expose a Gemini key in a public deployment; use a secure backend before production.
